# Развёртывание на GitHub Pages

## Быстрый способ
Загрузите **содержимое папки deploy** в корень репозитория.
Файл `index.html` уже содержит встроенные CSS и JavaScript, поэтому
интерфейс отобразится корректно, даже если остальные файлы не загружаются.

## Настройка GitHub Pages
1. Зайдите в репозиторий → **Settings** → **Pages**.
2. В разделе **Build and deployment** выберите:
   - Source: **Deploy from a branch**
   - Branch: **main** (или master), папка: **/(root)**
3. Нажмите **Save**.
4. Подождите 1–2 минуты и откройте ссылку вида
   `https://ИМЯ.github.io/ИМЯ-РЕПОЗИТОРИЯ/`
   (обязательно со слешем на конце).

## Если стили всё равно не применяются
- Откройте сайт, нажмите Ctrl+F5 (жёсткая перезагрузка).
- В DevTools → Application → Service Workers → Unregister, затем обновите страницу.
- В DevTools → Network проверьте, нет ли 404 у `styles.css` / `app.js`.
  При использовании встроенного `index.html` это не критично.
- Убедитесь, что файл называется именно `index.html` (регистр имеет значение).

## Важно
Не открывайте страницу как `file://...` — service worker может работать некорректно.
Только HTTP/HTTPS (GitHub Pages подходит).
